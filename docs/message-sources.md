## 读取规则

预设名称和默认网址位于 `src/shared/sources.ts`；列表链接、日期所在行、正文区域和 PDF 附件的 CSS 选择器位于 `src/main/source-reading-rules.ts`。新增网站预设时同时扩展这两个文件，并添加解析测试。

通用网页支持带日期的列表行和常见正文容器；动态渲染或结构特殊的网站需要单独适配。列表链接与 PDF 附件限定在所在网页的同一站点。自定义来源仅访问公开 HTTPS 地址，不附带账号 Cookie。

英语教学部部分通知正文是 WebPlus 内嵌 PDF。读取器从 `pdfsrc` 等属性取得附件，使用 PDF.js 提取文字；保留附件入口。扫描件、加密文件或读取失败的 PDF 可打开附件查看，当前不提供 OCR。每条通知最多提取 3 份 PDF，每份上限 20 MB、100 页、300,000 字符。

来源与通知缓存在 SQLite 中保存。禁用来源隐藏其通知，删除来源同时清理缓存；网址或读取预设变更后清理该来源旧缓存。刷新失败保留上次缓存并显示该来源错误，其他来源继续刷新。

## 验证

运行 `npm test` 检查迁移、缓存隔离、来源校验、解析和 PDF 文字提取；运行 `npm run build` 检查类型并构建桌面应用。
